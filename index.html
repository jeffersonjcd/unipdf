# Política de Privacidade — UniPDF **Última atualização:** 9 de outubro de 2026 ## 1. Introdução O UniPDF é um aplicativo para Windows que permite selecionar, organizar e combinar arquivos PDF em um único documento. Esta Política de Privacidade explica como o aplicativo acessa e processa arquivos durante sua utilização. ## 2. Coleta de dados pessoais O UniPDF não foi desenvolvido para coletar, armazenar ou transmitir dados pessoais dos usuários. O aplicativo não exige cadastro ou criação de conta para funcionar. ## 3. Processamento local de arquivos O processamento dos documentos PDF ocorre localmente no computador do usuário. O aplicativo acessa os arquivos selecionados pelo usuário exclusivamente para executar as funcionalidades solicitadas, como combinar documentos e salvar o arquivo resultante. Os documentos PDF não são enviados pelo aplicativo para servidores externos. ## 4. Armazenamento e compartilhamento de informações O UniPDF não mantém uma base de dados remota de usuários e não compartilha os documentos selecionados com terceiros. Os arquivos originais permanecem nos locais escolhidos pelo usuário, e o documento combinado é salvo no destino indicado pelo usuário. O aplicativo não possui, em sua versão atual, funcionalidades de sincronização em nuvem, publicidade personalizada ou rastreamento de atividades. ## 5. Permissões e acesso aos arquivos O aplicativo utiliza as janelas de seleção e salvamento de arquivos do Windows para permitir que o usuário escolha os documentos que deseja processar. O acesso aos arquivos está relacionado às funcionalidades solicitadas pelo usuário. ## 6. Segurança O processamento local reduz a necessidade de transmitir documentos a serviços externos para combinar PDFs. O usuário é responsável pela segurança do próprio computador, pela proteção dos arquivos e pelo local escolhido para salvar os documentos resultantes. Nenhum software pode garantir segurança absoluta em todas as circunstâncias. ## 7. Privacidade de crianças O UniPDF não coleta intencionalmente dados pessoais de crianças. O aplicativo é uma ferramenta local para manipulação de documentos e não possui recursos de interação social ou criação de perfis de usuários. ## 8. Serviços de terceiros A versão atual do UniPDF não depende de serviços externos para processar ou combinar arquivos PDF. A aquisição, o download ou a atualização do aplicativo por meio de plataformas de distribuição, como a Microsoft Store, pode estar sujeita às políticas de privacidade dessas plataformas. ## 9. Alterações nesta política Esta Política de Privacidade poderá ser atualizada caso novas funcionalidades alterem a forma como o aplicativo acessa, processa, armazena ou compartilha informações. A versão atualizada será publicada nesta página, com a respectiva data de revisão. ## 10.
